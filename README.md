# goit-js-hw-01

Simple JavaScript homework exercises for the GoIT course.

## Project Structure

- `index.html` — demo page that loads the task scripts
- `js/` — source files for the exercises (task-1.js, task-2.js, task-3.js)
- `prettierc.json` — code style configuration

## Run / Preview

1. Open `index.html` in your browser.
2. Or run a simple local server (recommended):

```bash
python -m http.server 8000
# then open http://localhost:8000
```

## Development

- Edit the exercise files in `js/`.
- Code style: project includes `prettierc.json`; run Prettier via your editor or CLI.

## Tasks

- Implement and verify behavior in `js/task-1.js`, `js/task-2.js`, and `js/task-3.js`.

## Notes

- This repository is a lightweight set of exercises; add tests or extra documentation as needed.
